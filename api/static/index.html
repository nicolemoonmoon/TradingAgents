TradingAgents Research Workbench

Internal research tool -- draft analysis and risk-review notes only. Not a trading system: no brokerage connection, no order execution. This tool triggers real LLM API calls and may incur real cost. Output is research-only analysis, not trading advice, and this system never places or automates any order.

Run settings

These settings are used only when you start a real analysis. Scanner, Compare Board, and Load Run do not use them.

Analysts

Default (market only) is the low-cost option. Selecting more analysts increases both cost and run time.

Starting an analysis creates a new run and uses DeepSeek.

Load Run only opens saved results. It does not start a new analysis.

Reviewing candidates is free. DeepSeek runs only when you click Analyze.

Analyze uses the analysis date / analysts / models / strategy profile from the shared run settings above. A candidate only shows results for a run started from its own "Analyze" button in this browser session -- it does not look up past runs for that ticker.
